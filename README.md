# RavenMind

RavenMind is a web-based character guessing game based on the Game of Thrones universe. Think of a character (real or fictional) and let the Three-Eyed Raven attempt to guess who it is through a series of "Yes/No" questions. 

## Features

- **Game of Thrones Aesthetic**: Dark coal backgrounds, blood-red primary colors, and antique gold glowing accents. 
- **Responsive UI**: Fully responsive application optimized for desktop and mobile play.
- **Interactive UI**: Animated background with floating fire embers and an interactive Raven character.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui + Tailwind CSS

## Running Locally

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
